# Majestic

A **magic and adventure** mod for Minecraft NeoForge — arcane-celestial magic: stars,
constellations, light and ether. Power is *earned by exploring* and *refined by ritual*.

## The idea

Three linked layers, each unlocking the next:

1. **Rituals & research** — multiblock altars and a graph of constellation nodes unlocked by what
   you find in the world.
2. **Spells** — schools, a single global *essence* resource, a focus item whose spell is engraved
   by ritual.
3. **Relics** — equippable artifacts with passives/actives and set synergies, forged in high-tier
   rituals.

The adventure side gates every layer behind exploration: a new dimension (**the Celestial Plane**),
structures and bosses.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.249
- Java 21

## Dependencies (required)

- [Astral Core](https://gitlab.com/stalking-dragons/minecraft/astral-core) — magic systems.
- [Almanac Core](https://gitlab.com/stalking-dragons/minecraft/almanac-core) — content-as-data, JEI, guide bridge.

Planned (not wired yet): [Expedition Core](https://gitlab.com/stalking-dragons/minecraft/expedition-core) (dimension / structures / bosses) and GeckoLib (boss / entity animation).

Optional (transitive via Almanac Core): JEI (recipe viewing), [Vellumli](https://gitlab.com/stalking-dragons/minecraft/vellumli) (in-game guide book).

All dependencies are installed as separate mods — Majestic bundles nothing.
