<h2>v0.0.0-beta.12 - Spanish, guide book &amp; creative tabs</h2>

<p>Fixes from the first playtest.</p>

<h3>Added</h3>
<ul>
<li><strong>Spanish translation</strong> (<code>es_es</code>): items, blocks, creatures, tabs, messages and the guide book.</li>
<li><strong>The Almanac</strong>, Majestic's guide book: given once the first time you join a world, and craftable from a book surrounded by 8 lapis lazuli.</li>
<li>Creative tabs <em>Majestic: Magic</em> and <em>Majestic: World</em>; spawn eggs also appear in the vanilla spawn egg tab.</li>
<li>The Astral Altar and Astral Pillar can now be held as items.</li>
</ul>

<h3>Fixed</h3>
<ul>
<li>The guide book never showed up in game.</li>
<li>A crash when unlocking the first research without Vellumli installed.</li>
<li>Several messages (focus, <code>/majestic status</code>, essence HUD) were always shown in English.</li>
</ul>

<h3>Changed</h3>
<ul>
<li><a href="https://www.curseforge.com/minecraft/mc-mods/vellumli">Vellumli</a> is now a <strong>required dependency</strong> (it displays the guide book). The CurseForge app installs it automatically.</li>
</ul>

<blockquote><strong>Early alpha.</strong> Some progression items (Starlight Focus, Astral Altar, Astral Pillar) cannot be obtained in survival yet &#8212; a progression pass is coming. The Warden of the Gate's animations are being reworked.</blockquote>
