<h2>v0.0.0-beta.2 - Expedition Core &amp; GeckoLib wired in</h2>

<p>Dependency-wiring release ahead of the Act I&#8211;II structures and bosses milestone &#8212; no new gameplay content yet.</p>

<h3>Added</h3>
<ul>
<li>Wired <a href="https://www.curseforge.com/minecraft/mc-mods/expedition-core">Expedition Core</a> as a real dependency, now that its structures + boss-encounter framework is published.</li>
<li>Wired <a href="https://www.curseforge.com/minecraft/mc-mods/geckolib">GeckoLib</a> as a real dependency, needed for the boss entities to come.</li>
<li>All four required dependencies (Astral Core, Almanac Core, Expedition Core, GeckoLib) are now declared on this file, so the CurseForge app/launcher installs them automatically when you install Majestic.</li>
</ul>

<h3>Notes</h3>
<ul>
<li>Alpha content is unchanged from beta.1 (Starlight school, four spells, hardcoded focus). This release only unlocks the dependencies for the next content milestone.</li>
</ul>

<blockquote><strong>Early alpha.</strong> This is a first playable slice, not a finished mod &#8212; expect missing features and rough edges between betas.</blockquote>
