<h2>v0.0.0-beta.1 - Alpha: the Starlight school</h2>

<p>First playable slice of Majestic: one school, four spells, a focus, and the essence resource that powers them.</p>

<h3>Added</h3>
<ul>
<li><strong>Starlight Bolt</strong> &#8212; a piercing hitscan that damages and blinds.</li>
<li><strong>Starlight Ward</strong> &#8212; Absorption and Regeneration for yourself.</li>
<li><strong>Starlight Reveal</strong> &#8212; marks nearby hostiles with Glowing.</li>
<li><strong>Starlight Surge</strong> &#8212; a burst of Speed.</li>
<li><strong>Starlight Focus</strong> item &#8212; casts Starlight Bolt on use (no engraving system yet), respects cooldown.</li>
<li>An essence HUD readout, visible while holding the focus.</li>
<li><code>/majestic status</code> debug command.</li>
<li>Wired <a href="https://www.curseforge.com/minecraft/mc-mods/astral-core">Astral Core</a> and <a href="https://www.curseforge.com/minecraft/mc-mods/almanac-core">Almanac Core</a> as real dependencies.</li>
</ul>

<h3>Fixed</h3>
<ul>
<li>Spell definitions were written to the wrong datapack path and would never have loaded.</li>
<li>A duplicated registry-creation listener that could have crashed mod loading.</li>
<li>Eager resolution of a registry holder before the registry was bound (<code>IllegalStateException: Registry not present</code>) &#8212; the mod would not start.</li>
<li>A possible crash when casting Starlight Bolt with no target in range.</li>
<li><code>runs.data</code> used <code>clientData()</code>, invalid on <code>net.neoforged.moddev</code> 2.0.142 &#8212; fixed to <code>data()</code>.</li>
</ul>

<h3>Notes</h3>
<ul>
<li>No crafting recipe for the focus yet &#8212; use <code>/give @s majestic:starlight_focus</code> or the creative inventory.</li>
<li>No dimension, structures or bosses yet. No ritual/engraving system &#8212; the focus always casts Starlight Bolt.</li>
</ul>

<blockquote><strong>Early alpha.</strong> This is a first playable slice, not a finished mod &#8212; expect missing features and rough edges between betas.</blockquote>
